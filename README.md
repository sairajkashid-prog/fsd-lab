# FSD Lab — Portfolio Webpage (CSS Basics)

Academic lab (Full Stack Development): a small personal portfolio webpage built
with plain **HTML and CSS**, used to demonstrate the three ways CSS can be
applied to a document.

## CSS techniques demonstrated

1. **Inline CSS** — `style` attribute directly on elements (e.g. the `<h1>`)
2. **Internal CSS** — a `<style>` block inside `index.html`
3. **External CSS** — styles pulled in from `style.css` via `<link>`

## Run it

Open `index.html` in any browser — no build step or server needed.

## Files

| File | Purpose |
|---|---|
| `index.html` | Page structure with inline + internal CSS |
| `style.css` | External stylesheet (navigation, layout, typography) |
